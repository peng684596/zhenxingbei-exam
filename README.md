# 振兴杯 · 增材制造理论备考训练

第19届“振兴杯”全国青年职业技能竞赛 · 学生组 **增材制造设备操作员赛项** 理论试题库备考训练网站。

> 公网访问：https://peng684596.github.io/zhenxingbei-exam/

## 功能

- **套题训练（6 套 × 100 题）**：覆盖 FDM / SLA / SLM / SLS / EBM / DLP / BJ 等工艺的 600 道选择题，每题配专业解析
  - 答对自动进入下一题；答错显示正确答案 + 解析
  - 左右滑动切换题目（支持触屏滑动、键盘 ← →、按钮）
  - 答题卡跳题、进度条、用时统计
  - 练习进度自动保存到浏览器本地，可随时“继续练习”；每套完成成绩长期保存
- **错题本（错题记忆）**：练习中答错的题自动收入；在错题巩固模式中答对即移出，直到清零
- **模拟考试**：随机抽取 100 题，100 分制，60 分及格，次数不限
  - 交卷前不显示对错，交卷后自动判分、显示错题解析
  - 考试错题自动加入错题本；历史成绩保存在本地

## 数据

- 题目来源：竞赛理论试题库（选择题 600 题，题号 1–600，按 100 题一套划分 6 套）
- 答案与题号一一对应；解析由 AI 基于增材制造专业知识整理（关键数值参考教材、工艺手册与国家标准）
- 数据以纯静态 JS 文件存放（`js/questions1.js` ~ `js/questions6.js`），无后端、无跟踪，学习记录只保存在你自己的浏览器里

## 技术

原生 HTML / CSS / JavaScript 单页应用，移动端优先，零依赖。可部署到任意静态托管（GitHub Pages / Netlify / 服务器等）。

## 本地使用

直接把 `index.html` 所在目录放到任意静态服务器即可，例如：

```bash
python -m http.server 8080
# 或 npx serve .
```

浏览器打开对应地址即可开始学习。
